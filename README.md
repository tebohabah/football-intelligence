# Football Intelligence Engine

A zero-budget-launch foundation for a serious football probability platform.

Included: daily fixtures, league/team search, 1X2, double chance, totals, BTTS, expected goals, correct scores, confidence, model agreement, explainable factors, top opportunities, model performance and methodology pages.

Production roadmap: historical warehouse, league-specific Elo, Dixon-Coles, xG attack/defence ratings, player availability, lineups, injuries, rest/congestion, referee/weather context, odds snapshots and de-vigging, ensemble ML, Monte Carlo simulation, probability calibration, walk-forward validation, Brier/log-loss tracking, immutable prediction records, model versioning, drift monitoring and automated post-match grading.

Important: probabilities are forecasts, not guarantees.
